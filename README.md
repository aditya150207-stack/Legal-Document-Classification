
# Legalised ML
## Legal Document Classification System

A machine learning project that classifies legal documents into six categories.

### Categories
- Property Law
- Family Law
- Criminal Law
- Consumer Law
- Contract Law
- Employment Law

### Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Streamlit
- Pandas

### How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Train the model:

   python train_model.py

3. Start the application:

   streamlit run app.py

### Model Performance
The current model achieved approximately 85.42% accuracy on its held-out test split using an illustrative synthetic dataset.

### Disclaimer
This is an academic demonstration project, not a legal advice system. Predictions are not verified legal conclusions.
